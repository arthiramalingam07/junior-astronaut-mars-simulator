# Junior Astronaut Mission Trainer

## Mars Habitat Survival Simulator

An educational web application that teaches students
how to manage resources in a simulated Mars habitat.

## Technologies

- Python
- Flask
- HTML
- CSS
- JavaScript
- Chart.js
- NASA Image and Video Library API

## Features

1. Seven-day Mars survival mission.
2. Power management.
3. Oxygen management.
4. Water management.
5. Food management.
6. Mission actions.
7. Random Mars events.
8. Educational feedback.
9. Resource history charts.
10. Mission success and failure detection.
11. Final mission report.
12. NASA Mars photographs.
13. Automatic fallback image.

## Installation

Clone the repository:

git clone YOUR_REPOSITORY_URL

Move into the project directory:

cd junior-astronaut-mars-simulator

Install dependencies:

pip install -r requirements.txt

Run the application:

python app.py

Open your browser:

http://127.0.0.1:5000

## Run tests

pytest -q

## Educational Purpose

This application uses simplified resource
percentages and is not a scientifically
validated Mars habitat engineering model.
